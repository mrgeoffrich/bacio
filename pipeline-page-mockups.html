Pipeline page — card state mockups

Flat HTML design pass for the redesigned Pipeline page, built on bacio's real design tokens (Nunito + JetBrains Mono, blueberry-sorbet sky accent, gelato status colours). Shows how cards look across backlog, in-pipeline, and shipping states.

Core principle: the issue card only ever shows the issue itself — key, title, tags, feature glyph. Every bit of processing (the job chain, controls, the active job's todos, open questions, ship status) lives in the surrounding stage area, never inside the issue card.
